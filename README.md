# 大迪在面壁｜岩馆扫码播报

现场扫码后写入 CloudBase 信号、跳转小红书，并由 iPad 展示页播报固定语音。

## 正式入口

- 管理与展示入口：<https://scan.dadi-climb.cn/>
- CloudBase 环境：`dadi-climb-d6g91rnn034b36f1f`
- 数据库集合：`scan_signals`

## 文件

- `index.html`：管理、现场展示、扫码反馈和备用播报台。
- `announce.m4a`：固定普通话播报音频。
- `ready.m4a`：iPad 启动时的“播报已开启”确认音。

## 现场流程

1. 管理页创建活动。
2. 在现场 iPad 打开展示页，点一次“开启并试听”。
3. 听到“播报已开启”后，操作层会自动消失，只留下对外展示内容和二维码。
4. 岩友扫码后写入信号并跳转小红书，iPad 按顺序播报。

iPad 需要保持展示页可见，并关闭静音、调高媒体音量、避免锁屏。切到其他 App 或熄屏后，iPadOS 不保证网页继续监听和发声；回到展示页时会自动补查漏掉的扫码。

同一场活动不要同时开启展示页播报和独立播报台，否则两台设备都会出声。
